# Manual de operação — Interpreter × Andre

Site estático com as regras de trabalho, o método, as entregas e as capacidades do Interpreter neste PC.

## Conteúdo
- **Regras** — comunicação, autonomia, confirmações e segredos.
- **Método** — perceber, planear, executar, verificar, reportar.
- **Entregas** — pasta de transferência na Google Drive.
- **Ferramentas** — o que está instalado.
- **Capacidades e limites** — o que funciona e o que está bloqueado.

## Estrutura
```
index.html    conteúdo
styles.css    tema escuro, layout responsivo
app.js        navegação ativa, botão copiar, estado do header
```

Sem dependências, sem build. Abrir `index.html` ou publicar em GitHub Pages.
